# Problem Solving with TypeScript & OOP

## Project Overview

This project is based on problem-solving using TypeScript and Object-Oriented Programming (OOP). It contains different TypeScript problems that helped me practice basic and advanced concepts.

The project covers functions, optional parameters, union types, tuples, generics, interfaces, classes, inheritance, access modifiers, and asynchronous programming using Promises.

## Project Files

- **solutions.ts:** Contains all eight TypeScript problem solutions.
- **type-vs-interface.md:** Explains the differences between Type Alias and Interface in TypeScript.
- **access-modifiers-oop.md:** Explains access modifiers in TypeScript OOP with code examples.
